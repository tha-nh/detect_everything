# Core
- Small Python YOLO-World object-detection demo with CLI in `app.py`, GUI in `gui.py`, model wrapper in `detector.py`.
- Supported media extensions are mirrored in CLI/GUI constants: images `.jpg/.jpeg/.png/.bmp/.webp`, videos `.mp4/.avi/.mov/.mkv/.wmv`.
- Output artifacts go under project-local `output/` by default.
- Read `mem:tech_stack` for dependencies/runtime, `mem:conventions` for style, `mem:suggested_commands` for common commands, `mem:task_completion` before finishing code tasks.
